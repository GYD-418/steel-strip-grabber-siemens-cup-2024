# "穿针引线"——轧钢带头智能抓取装置

2024 年西门子杯 / CIMC 中国智能制造挑战赛参赛作品。

## 项目简介

针对轧钢生产线场景，设计一套轧钢带头智能抓取装置，实现钢带头的自动识别与抓取引导，替代人工穿针引线作业。

## 目录结构

```
├── 轧钢带头抓取装置代码/   # STM32 Keil MDK 工程（下位机控制）
├── 西门子.HMI             # 西门子 HMI 组态工程
├── 扫描件_2025年CIMC中国智能制造挑战赛.pdf
└── 演示视频 / 图片
```

## 技术栈

- **下位机**：STM32 + Keil MDK（C 语言）
- **上位机**：西门子 HMI 组态（WinCC）
